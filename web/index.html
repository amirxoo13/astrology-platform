استفاده از API

می‌توانید مستقیماً از API استفاده کنید:

Health Check:

curl http://localhost:8080/api/health

Birth Chart (مثال آلبرت انیشتین):

curl -X POST http://localhost:8080/api/v1/birth-chart \ -H "Content-Type: application/json" \ -d '{ "datetime": "1879-03-14T11:30:00", "timezone": "Europe/Berlin", "latitude": 48.4011, "longitude": 9.9876 }'

Aspects:

curl -X POST http://localhost:8080/api/v1/aspects \ -H "Content-Type: application/json" \ -d '{ "datetime": "1879-03-14T11:30:00", "timezone": "Europe/Berlin", "latitude": 48.4011, "longitude": 9.9876 }'
