🪐 Swiss Ephemeris

محاسبات نجومی دقیق با استفاده از استاندارد جهانی Swiss Ephemeris. پشتیبانی از 15 سیاره و سیارک با دقت ثانیه‌ای.

🏠 سیستم‌های خانه

پشتیبانی از Placidus و 14 سیستم خانه دیگر. محاسبه دقیق cusps با الگوریتم‌های پیشرفته.

✨ جنبه‌ها

تحلیل کامل جنبه‌ها شامل مقارنه، تقابل، تثلیث، مربع، و سکستیل با orb دقیق.

🔥 توزیع عناصر

محاسبه توزیع عناصر (آتش، زمین، هوا، آب) با سیستم وزن‌دهی حرفه‌ای مانند Astro-Seek.

👑 سیارات حاکم

رتبه‌بندی سیارات حاکم با امتیازدهی مدرن شامل Sign، House، Angle، Ruler، و Aspects.

⚡ تحلیل سرعت

مقایسه سرعت سیارات با میانگین. تشخیص حرکت سریع، کند، و برگشتی (Retrograde).

🤖 استفاده از بات تلگرام

برای ساخت چارت ناتال از طریق تلگرام:

  1. در تلگرام بات را پیدا کنید و /start را بزنید
  2. روی "🌟 ساخت چارت ناتال" کلیک کنید
  3. نام شخص را وارد کنید
  4. تاریخ تولد (YYYY-MM-DD) را وارد کنید
  5. ساعت تولد (HH:MM) را وارد کنید
  6. نام شهر یا مختصات (lat,lon) را وارد کنید
  7. اطلاعات را تایید کنید و چارت خود را دریافت کنید!

🌐 استفاده از API

برای توسعه‌دهندگان:

# چک کردن سلامت API (از طریق Nginx، همان مسیری که این صفحه استفاده می‌کند) curl http://localhost:8080/api/health # ساخت چارت ناتال (از طریق Nginx) curl -X POST http://localhost:8080/api/v1/birth-chart \ -H "Content-Type: application/json" \ -d '{ "datetime": "1879-03-14T11:30:00", "timezone": "UTC", "latitude": 48.40, "longitude": 9.99 }' # نکته: پورت 8000 (کانتینر API) به‌صورت مستقیم روی هاست منتشر نشده و فقط # از داخل شبکه Docker یا از طریق پروکسی Nginx (مسیرهای بالا) در دسترس است.
